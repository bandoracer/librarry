## Backend

The backend owns provider credentials, metadata normalization, provider health,
matching policy, acquisition workers, and Postgres persistence. Provider tokens
never need to be exposed to the browser.

Authentication combines configured Forms/Basic access and compatible API keys.
A valid API key authorizes compatible clients regardless of the browser method;
with method `none`, a configured key still protects non-public `/api/` routes.
See [authentication](../guides/operations.md#authentication) for public auth/probe
endpoints and the session contract.
